# MASTER PROMPT — JANVI GUPTA PORTFOLIO STARTER

Build the initial version of a responsive personal portfolio website for Janvi Gupta using the supplied reference assets and `content/portfolio-content.json` as the source of truth.

## Scope for this first version
Create only the portfolio framework and these sections:
1. Hero banner: a distinctive personal logo/wordmark inspired by `assets/signature-reference.jpg`, plus the exact headline “Welcome to my portfolio”.
2. About Me: show the exact quote and About text supplied in `portfolio-content.json`.
3. Work Experience: present all three supplied experiences in a clean timeline or stacked editorial cards.
4. Skills & Interests: use only the listed skills and interests. The specific software and AI skill names are not available in the supplied CV text, so leave clear editable placeholders and do not make them up.
5. Education and Achievements: include the supplied details in concise, clearly separated sections.
6. Selected Work: show a simple “Projects coming soon” placeholder area. Do not invent case studies or add fictional project thumbnails. This area must be easy to extend later.
7. Contact: use supplied details, but make the contact section easy to edit and do not add unnecessary personal information.

## Visual identity
Use the palette reference in `assets/palette-reference.jpg`. The key palette values are:
- Rose: #C9788A
- Soft pink: #E29C9C
- Blush beige: #E6BEAE
- Warm beige: #EEDAC5
- Ivory: #F5F5DC

The design should feel light, warm, elegant, minimal, personal, and professional. Use ivory or warm beige for the main backgrounds, blush/soft pink for restrained accents, and a dark warm charcoal for readable text. Do not put body text directly on saturated rose without checking contrast. Use generous whitespace, clear hierarchy, restrained borders, subtle shadows, and accessible contrast. Avoid clutter, loud gradients, heavy animation, and excessive rounded cards.

## Logo instructions
Use the supplied signature image as the visual reference. Create a polished, simplified logo/wordmark based on Janvi's own handwritten signature. Preserve its recognisable handwritten quality; do not substitute a generic icon or change the name. If you cannot produce a faithful vector version, use the supplied image as a reference and create an editable logo treatment without pretending it is a precise trace. Keep the logo small enough to complement, not overpower, the hero headline.

## Content integrity
- Treat the uploaded documents and JSON as source material.
- Preserve the supplied About quote and paragraphs exactly.
- Do not invent employers, responsibilities, dates, achievements, software tools, AI skills, statistics, projects, research, or qualifications.
- Keep supplied experience wording faithful; improve only small grammar issues without changing meaning.
- The CV and About Me document contain different descriptions of the master's programme/institution. Use the current user-provided About Me content for the displayed master's programme: “Visual Experience Design at Karnavati University.”
- Mark any uncertain organisation spelling or dates as editable and ask for confirmation rather than silently guessing.
- Do not publish phone numbers or email addresses unless the owner wants them visible; make the contact details easy to remove or edit.

## Build requirements
- Build the homepage first; do not attempt to create the detailed project case studies yet.
- Keep components, content, and assets organised so future projects can be added without rebuilding the whole site.
- Make the navigation and section links functional.
- Ensure the page is responsive on desktop, tablet, and mobile.
- Use semantic, accessible HTML and meaningful alt text.
- Keep the result easy for a beginner to edit.
- Before finalising, list any content needing confirmation, particularly software skills, AI skills, employer spelling, dates, and public contact preferences.
